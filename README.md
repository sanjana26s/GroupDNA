# GroupDNA – WhatsApp Group Chat Analyzer

## About
GroupDNA is a Python-based project that analyzes WhatsApp group chat
data to discover communication patterns, member activity, and
interesting group personalities.

## Features
- WhatsApp chat parsing
- Group overview and member statistics
- Most active member identification
- Busiest day and hour analysis
- Activity heatmap using NumPy
- Most frequently used words
- Average message length
- Response time estimation
- Longest silent period analysis
- Fun personality indicators

## Technologies Used
- Python
- NumPy
- Google Colab

## How to Run
1. Download the notebook.
2. Open it in Google Colab.
3. Upload your WhatsApp chat export.
4. Run the notebook cells in order.

## Note
Personality labels are simple, keyword-based activity indicators,
not psychological assessments.
